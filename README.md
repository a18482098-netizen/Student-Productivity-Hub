# Student Productivity Hub

A complete Android productivity solution for students to manage tasks, attendance, GPA, timetable, notes, and reminders in one place.

## Features

### 1. Dashboard/Home Screen
- Beautiful welcome screen with student profile
- Quick statistics cards (tasks, attendance, GPA, reminders)
- Material Design 3 UI

### 2. Task Manager Module
- Add, edit, delete tasks
- Task priority levels (High, Medium, Low)
- Due date selection
- Search and filter functionality
- RecyclerView with CardView display

### 3. Attendance Tracker Module
- Add/edit/delete attendance records
- Auto attendance percentage calculation
- Subject-wise statistics
- Attendance status indicators

### 4. GPA Calculator Module
- Add courses with credit hours
- Grade selection
- Automatic GPA calculation
- Save semester records
- Edit/delete courses

### 5. Timetable Module
- Weekly timetable view
- Add/edit/delete class schedules
- Day-wise view
- RecyclerView cards

### 6. Notes Storage Module
- Create, edit, delete notes
- Search functionality
- Local SQLite storage
- Note details view

### 7. Reminder Notifications Module
- Create reminders with date and time
- Local notifications
- Edit/delete reminders
- Alert system

## Technology Stack

- **Language**: Java
- **Database**: SQLite with Room
- **UI Framework**: Material Design 3
- **Navigation**: Bottom Navigation + Navigation Drawer
- **Architecture**: MVVM with LiveData

## Build & Run

1. Open in Android Studio
2. Sync Gradle files
3. Run on emulator or device
